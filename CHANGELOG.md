# Изменения

## Доработки трекера и планера

- Трекер пробников ЕГЭ по русскому языку, профильной математике, химии и биологии поддерживает первичные/набранные баллы и необязательный тестовый балл из 100.
- Статистика сравнивает результаты по проценту от максимума, чтобы сводка «Все предметы» не сравнивала напрямую разные шкалы.
- История пробников следует фильтру выбранного предмета; редактирование записи открывается в отдельном окне.
- Исправлено обновление временных меток изменённых локальных ключей для Supabase sync. Схема таблицы и существующие ключи хранения не менялись.
- Обновлена версия кэша Service Worker, чтобы опубликованная версия приложения могла получить обновлённые файлы.

## Проверки

- Проверен синтаксис всех встроенных JavaScript-блоков с помощью Node.js.
- Проверены наличие основных разделов, полей и обработчиков сохранения/синхронизации.
- Реальное подключение к Supabase и сохранность облачных данных из этой среды не проверялись; облачные записи не изменялись.
