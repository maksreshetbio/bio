# Олимпиадная биология — PWA + бесплатная синхронизация

Эта версия сохраняет приложение локально и добавляет необязательную синхронизацию Android ↔ Windows через Supabase.

## Что синхронизируется

- чек-листы недельного плана;
- еженедельные заметки;
- планер тренировок;
- заметки и список дел;
- карточки плана дня, сохранённые отдельно для каждой даты;
- результаты пробников ЕГЭ по русскому языку, профильной математике, химии и биологии;
- другие данные, которые приложение хранит под префиксом `olymbio:`.

Синхронизация сделана local-first: приложение работает и без интернета, а после входа сверяет локальные данные с облаком. Для отдельных ключей используется время изменения. При локальном изменении ключа его метка времени обновляется, чтобы новые данные корректно участвовали в синхронизации.

## Пробники ЕГЭ

Для каждой записи можно указать предмет, дату, тип работы, набранные и максимальные баллы, вариант/тему и разбор ошибок. При наличии отдельно сохраняется тестовый балл из 100. Старые записи с полями `points` и `max` продолжают отображаться; дополнительные поля необязательны. Результаты можно редактировать в отдельном окне и экспортировать в JSON.

## План дня и заметки

Карточки плана хранятся отдельными ключами для каждой даты. Выполнение задачи не переносит её на другой день. Задачу можно добавить вручную, выбрать из недельного плана или добавить из списка дел. Заметки и пункты списка дел можно редактировать; список дел при необходимости связан с планом дня.

## Важное про безопасность

В `config.js` можно размещать только URL проекта и publishable key (или старый `anon` key). **Не вставляй service_role / secret key**: они предназначены только для серверной части.

## Настройка Supabase

### 1. Создай проект

Открой Supabase и создай бесплатный проект.

### 2. Создай таблицу

В Supabase открой SQL Editor → New query и вставь весь текст из `supabase.sql`. Нажми Run.

### 3. Получи URL и ключ

В Supabase открой Settings → API Keys (или Connect). Скопируй:
- Project URL;
- Publishable key (`sb_publishable_...`) либо legacy `anon` key.

Вставь их в `config.js`:

```js
window.OLYMBIO_SYNC_CONFIG = {
  url: "https://ТВОЙ-ПРОЕКТ.supabase.co",
  publishableKey: "ТВОЙ-PUBLISHABLE-KEY"
};
```

### 4. Включи регистрацию по email

В Supabase открой Authentication → Providers → Email и оставь Email включённым.

Для самого простого варианта можно оставить подтверждение email выключенным. Если подтверждение включено, после регистрации нужно подтвердить адрес из письма.

### 5. Размести PWA на HTTPS

Для Android и Windows удобнее всего GitHub Pages. Создай репозиторий, загрузи содержимое этой папки в корень репозитория и включи Settings → Pages → Deploy from a branch → `main` / root.

После публикации открой получившийся `https://...github.io/...` адрес. GitHub Pages поддерживает HTTPS.

### 6. Установи приложение

**Android:** открой сайт в Chrome → меню → «Установить приложение» / «Добавить на главный экран».

**Windows:** открой сайт в Edge/Chrome → меню браузера → установка сайта как приложения.

### 7. Подключи один аккаунт на обоих устройствах

На Android:
1. Открой раздел «Синхронизация».
2. Нажми «Создать аккаунт».
3. Введи email и пароль.
4. Если Supabase просит подтвердить email — подтверди его.
5. Войди.
6. Нажми «Синхронизировать сейчас».

На Windows:
1. Открой тот же сайт.
2. Введи тот же email и пароль.
3. Нажми «Войти».
4. Приложение загрузит общие данные.

После этого изменения будут автоматически отправляться в облако с небольшой задержкой, а кнопку «Синхронизировать сейчас» можно использовать для принудительной проверки.

## Как не потерять данные

Перед первым подключением аккаунта рекомендую нажать «Экспорт прогресса» и сохранить JSON-файл как резервную копию.

Если на двух устройствах одновременно менялась одна и та же запись, для одного и того же ключа при синхронизации используется более позднее время изменения. Поэтому не редактируй одну и ту же заметку одновременно на двух устройствах.

## Если что-то не работает

- `Нужно настроить config.js` → URL/ключ не вставлены или указан пример.
- `Ошибка чтения облака` / `Ошибка сохранения` → проверь, что SQL из `supabase.sql` выполнен и RLS/policies созданы.
- Не входит аккаунт → проверь Email provider и подтверждение email.
- PWA не устанавливается → сайт должен открываться через HTTPS, а не как `file://`.

## Файлы

- `index.html` — приложение;
- `config.js` — твои публичные настройки Supabase;
- `supabase.sql` — таблица и RLS-политики;
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA.

## Дополнительные инструменты

- **План дня:** отдельные карточки по датам, времени и описанию; можно добавить задачу вручную или выбрать пункт недельного плана. Невыполненные карточки остаются в исходной дате.
- **Заметки и список дел:** заметки можно создавать, редактировать и удалять; дела можно отмечать выполненными или добавлять в план дня.
- **Пробники ЕГЭ:** отдельные результаты по русскому языку, профильной математике, химии и биологии; дата, тип работы, набранные баллы, максимум, вариант, ошибки и следующий шаг. Записи редактируются и экспортируются.
- Все новые записи сохраняются под префиксом `olymbio:` и участвуют в существующей синхронизации `app_state` через Supabase. План дня хранится отдельным ключом для каждой даты.
- Кнопка сброса очищает только отметки чек-листов; заметки, пробники, тренировки и планы сохраняются.

Перед публикацией новой версии рекомендуется скачать экспорт прогресса и проверить синхронизацию в аккаунте Supabase на одном устройстве, затем на втором.
